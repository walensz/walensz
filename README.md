### Overview

I am a software developer focusing on web and mobile applications, and a graduate of **Universitas Bina Sarana Informatika**. Currently, I work part-time as a Full-Stack Web Developer at **Radhika Sanskara Ignacia**, where I build and maintain web systems from database design to user interfaces.

My day-to-day work revolves around the PHP and JavaScript ecosystems—primarily using Laravel, React, and Next.js for the web, alongside Flutter for cross-platform mobile development.

Outside of writing code, I spend most of my free time running, gaming, and reading novels or comics.
